# Œil extérieur de Kyra

Protocole de survie n° 3. Un robot GitHub, hors du serveur de Kyra, regarde aux 15 minutes si elle répond.
Muette trois fois de suite : un texto à Emil (une fois par panne), et un autre au retour. Les numéros et la clé
d'envoi sont des secrets du dépôt, jamais dans ce code.
